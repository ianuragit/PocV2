# 0006: Stages 2 and 3, stage select and lazy loading

Status: accepted (M6).

## Stages

| Stage            | Areas                                                                                                             | Stops | Enemies   | Model               |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- | ----- | --------- | ------------------- |
| 1 Metro Station  | ticket hall, platform and train, service tunnel, depot boss                                                       | 10    | 35 + boss | 721 KB, 8,666 tris  |
| 2 Studio Backlot | lot street on a dolly track, Sound Stage 7 with a castle-wall set, prop warehouse, water-tank boss on a prop boat | 9     | 29 + boss | 861 KB, 10,369 tris |
| 3 Hillside Dam   | mountain road, dam crest and gatehouse, turbine hall, control-room boss                                           | 9     | 28 + boss | 671 KB, 8,070 tris  |

- Stages 2 and 3 are generated by `tools/greybox/stage2.ts` and `stage3.ts` on a shared kit
  (`tools/greybox/kit.ts`), in the same flat-shaded style as stage 1. `npm run greybox` builds all three.
- The clearing bot finishes each on every difficulty with no hits taken and no continues. Stage 2:
  62 hits, 67,700. Stage 3: 60 hits, 65,300. Both bots found layout bugs on the first pass (a cover
  box and a civilian on firing lines in stage 2), which were fixed in the generator.
- Rank thresholds follow stage 1's rule: a perfect body-shot run is an A; S needs head shots and
  disarms. Stage 2: S 78,000 / A 60,000 / B 36,000. Stage 3: S 75,000 / A 57,000 / B 35,000.

## Stage select and unlocks

- The title has a stage button that cycles through open stages. Stage 1 is always open; each later
  stage opens when the one before it has been cleared on any difficulty (saved in `cleared`). The
  results screen says when a clear opens a new stage. `?stage=2` or `?stage=3` opens one directly.
- High scores stay per stage and difficulty.

## Lazy loading

- `public/data/stages/index.json` lists stage ids and names, so the title can show them without
  downloading any stage.
- A stage's JSON, markers and `.glb` are fetched only when that stage is chosen, behind the loading bar.
  A browser test checks that opening the title requests no stage 2 or 3 file.
- The spec asked for stage 2 and 3 _code_ chunks too. There is no stage-specific code: stages are pure
  data, so there is nothing to split.

## Music

Each stage plays the shared themes in its own key and tempo (stage 2 up a minor third and 4% faster,
stage 3 down a tone and 7% faster).
